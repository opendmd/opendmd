OpenDMD installer

Put the OpenDMD firmware and its web app on the display's ESP32 over USB, from this page.

ESP32 DevKit V1

The ESP32 DevKit V1: the small board with a USB socket that plugs into the DMDoS board. Most displays have this one.

This browser cannot talk to a USB serial port. Use Chrome, Edge, Opera or Firefox 151+ on a desktop. This page must be opened over https or from localhost.

A board that already runs OpenDMD is recognised: the installer shows its version and offers Update (settings kept), Change Wi-Fi, Visit device and its logs. On a first install it asks whether to Erase device: tick it (it erases everything on the board), and when it is done it asks for your WiFi.

Before you start

  1. Chrome, Edge, Opera or Firefox 151+ on a desktop computer (Windows, macOS, Linux, ChromeOS). Safari has no Web Serial.
  2. Plug the ESP32 DevKit V1 into the computer with a USB data cable. On Windows and older macOS the board's USB chip (CH340) may need its driver.
  3. Leave the microSD card in or out; the installer never touches it.

Install

  1. Click the Install button and choose its serial port (often "USB Serial", "CH340" or ttyUSB0).
  2. A board running OpenDMD introduces itself (Improv Serial over USB): its hostname, OpenDMD <version>, and Update OpenDMD when the versions differ (it writes the six parts below, the settings stay), Change Wi-Fi, Visit device (its address), Logs & Console and Erase User Data (a full install with erase). Anything else, including OpenDMD older than this, gets Install and the question whether to Erase device (the box starts unticked):
    • Ticked (a new board, or one that ran DMDoS or other firmware): the whole flash is erased first. That includes the player's settings in NVS: WiFi network and password, brightness, the playlist, the schedule and night window, and Follow RePlayOS. When it is done, Next asks for your WiFi (the board lists the networks it sees), the board joins and saves it, and Visit device opens the web app. Skip that and the board starts as the open WiFi access point OpenDMD-Setup (it can take a minute or two to appear); join it and enter your network.
    • Unticked (an update of a board already running OpenDMD): only the firmware, its updater, the web app, the bootloader and the partition table are written. The settings stay, and the player comes back on your network.
  3. Wait for it to finish (about a minute), then the board restarts by itself. The panel stays dark while the installer writes over USB, and lights up when the board restarts. Open http://opendmd.local/, or Visit device.

If the installer cannot connect, hold the board's BOOT button while it says "connecting", or unplug and try again.

What gets written

ESP32 DevKit V1, its manifest:

partoffset
reading the manifest…

The six parts: the bootloader, the partition table, otadata erased (so the board boots the firmware), the firmware, the small updater that installs later firmware updates sent over WiFi, and the web app. The same six merged into one image the size of the flash, opendmd-<version>-4mb-full.bin, sits beside them for tools that flash one file at offset 0 (esptool write-flash 0 …): that rewrites the whole flash, settings included. Without a browser, from a checkout: make fw-release-flash.

Updating only the web app

The web app lives in the board's flash and can be updated over WiFi without this page: make www-push HOST=opendmd.local, or the Web app section of http://opendmd.local/setup.

OpenDMD is open source, MIT or Apache 2.0. The firmware and the web app this page installs are built on other open-source software, listed with their licences in the firmware's notices and the web app's. This page uses ESP Web Tools (Apache 2.0), served with this page: its notices.
